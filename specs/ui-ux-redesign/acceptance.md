# Acceptance Criteria: UI/UX Redesign (`specs/ui-ux-redesign`)

All items remain `[ ]` until verified by code inspection, automated tests, and rendered screenshot evidence:

- [x] **AC-U01 (P0 System Bars Light/Dark)**: Status bar and navigation bar icons are clearly legible in both `ThemeMode.LIGHT` and `ThemeMode.DARK` on physical Android hardware (`SM-G988B` — `docs/screenshots/15-home-light.png`, `16-profile-light.png`, `01-home.png`).
- [x] **AC-U02 (Home)**: Home answers target exam, active session progress (`X dari Y soal`), next lesson, and single primary action cleanly with zero promotional blurb, zero repeated scale descriptions, and no nested cards (`docs/screenshots/01-home.png`, `15-home-light.png`).
- [x] **AC-U03 (Learn)**: Filter chips remain on a single horizontally scrollable row without wrapping into a multi-row block; concise module divider rows wrap cleanly without clipping; OER Material Bank remains accessible via `[Bacaan OER]` tab without burying curriculum modules (`docs/screenshots/03-learn-modules.png`, `04-module-detail.png`, `13-material-bank-oer.png`).
- [x] **AC-U04 (Exam / Practice)**: Question screen eliminates card-inside-card borders, suppresses raw internal IDs (`ITP01-L01`, `CHOICE_SINGLE`) from primary exam prompts, uses compact audio player with speed dropdown (Practice mode), keeps Practice/Strict rules intact, and respects `imePadding()` / navigation bars (`docs/screenshots/05-practice-packs.png`, `06-exam-listening.png`, `12-navigator-140.png`, `scratch/exam_light.png`).
- [x] **AC-U05 (Profile -> Model Manager)**: `ProfileScreen` separates Preferences, Offline Content, Offline AI, and Privacy & Data cleanly; SAF imports, installed model activation/deletion, and Hugging Face catalog + expandable technical metadata live inside `ModelManagerScreen` within 3 taps from Home (`docs/screenshots/10-profile-ai-saf.png`, `11-profile-security-r8.png`, `14-model-manager.png`).
- [x] **AC-U06 (Chat & Progress & Results)**: Chat keeps clean thread/composer with formatted citations and zero chip bars above messages; Progress follows 4-section hierarchy with genuine metrics; Results removes nested outlined cards per review item (`docs/screenshots/07-results.png`, `08-progress-analytics.png`, `09-ai-chat-rag.png`).
- [x] **AC-U07 (Accessibility & Adaptive Tests)**: Minimum `48dp` interactive touch targets, `2.0x` font scaling, Light/Dark modes, `320dp` / `360dp` / `412dp` / `960dp` layouts verified in `UiAndAccessibilityTest.kt` (`43/43` unit & Robolectric tests pass), `lintDebug` (`0` errors), and R8 `assembleRelease` (`aapt2` verified `versionCode=4`, `versionName=1.2.0`, `0` `INTERNET`, `0` `application-debuggable`).
- [x] **AC-U08 (Visual & Local QA Sign-Off)**: Before/After screenshots (`v1.1.1` vs `v1.2.0`) from `SM-G988B` inspected visually; zero crashes in `logcat`; local DevSecOps gates (secret scan `0` hits across `299` files, unit tests, lint, R8 build) green prior to push & CI monitoring.
