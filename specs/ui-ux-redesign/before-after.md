# Before / After UI/UX Audit & Verification (`specs/ui-ux-redesign`)

- **Application**: English Prep AI (`com.englishprep.ai`, `v1.2.0` / `versionCode = 4`)
- **Audit Target**: Physical Samsung Galaxy `SM-G988B` (Android 13, `1080x2400`, Light & Dark modes) + Robolectric Compose UI/Accessibility harness (`w320dp @ 2.0f`, `w360dp`, `w412dp`, `w960dp`)
- **Methodology**: Spec Kit (`specs/ui-ux-redesign/{spec,audit,plan,tasks,acceptance}.md`), BMAD review (`docs/reviews/bmad-ui-ux-redesign.md`), Clean MVVM / Material 3 editorial tokens (`docs/design-system.md`)
